强化学习笔记：从基本概念到贝尔曼方程

发表于2026-09-20|更新于2026-10-17|强化学习

一、基本概念

强化学习（Reinforcement Learning, RL）本质上是一门关于“决策”的科学。

如果说监督学习是“跟着老师学”（有标准答案），无监督学习是“自己找规律”（找特征），那么强化学习就是“在摸爬滚打中长记性”。它模仿了人类和动物最原始的学习方式：通过与环境互动，吃一堑长一智，最终总结出一套生存法则。

核心直觉：训练智能体的“胡萝卜加大棒”

想象你正在玩《超级玛丽》。你不知道游戏通关的完美代码是什么，系统也不会告诉你“这一步必须按跳跃键”。系统只会给出一种反馈：得分（Reward）。

例如，我们可以设定：踩死蘑菇获得正奖励，掉入深坑导致死亡并获得负奖励。负奖励是一种惩罚，但不等于“绝对禁止”：如果后续收益足够高，智能体也可能选择承受惩罚。为了拿到更高的累计奖励，你（智能体）必须根据当前的状态（State），不断尝试按不同的键（Action），并根据获得的奖励（Reward）来调整自己的行动策略（Policy）。这里可以先把状态理解为马里奥的位置、速度、敌人位置等游戏信息，而画面是我们观察这些信息的窗口。

同时，在一场游戏中，你不可能只遇见一种状态，所以我们把所有可能状态的集合叫做状态空间（State Space）。

当你按下向右键后，马里奥的位置发生改变，游戏就从一个状态进入了下一个状态，这个过程叫做状态转移（State Transition）。跳跃、获得 Buff，甚至敌人的移动，都可能带来状态变化。而在一个状态下，你可以选择的所有动作构成了该状态的动作空间（Action Space of a State）。

把这些概念串起来：智能体在当前状态下采取动作，环境给出奖励，并转移到下一个状态。这样连续交互形成的序列，我们称之为轨迹（Trajectory）：

$$S_0, A_0, R_1, S_1, A_1, R_2, S_2, \ldots$$

其中，$S_t$ 是第 $t$ 步的状态，$A_t$ 是在该状态下采取的动作，$R_{t+1}$ 是采取这个动作后获得的奖励，$S_{t+1}$ 是接下来的状态。

在这个例子中，我们把马里奥掉入深坑或成功拔下关底旗子设为一次游玩的结束。这种宣告流程结束的特殊状态，被称为终止状态（Terminal State）。而从游戏开局一直进行到触发终止状态为止，这一个从头到尾的完整游玩过程，在强化学习中被称为一个回合/幕（Episode）。

当马里奥完成一个回合后，我们可以把这一路获得的奖励加起来，评价这次游玩表现。在暂不考虑折扣时，从某一步开始直到回合结束的奖励之和，就是这一步的回报（Return）。注意，回报是累计奖励，不是最后一步的奖励。同一个策略可能因为环境或动作选择的随机性而得到不同的回报，所以评价策略优劣时，我们通常关注的是期望回报，也就是遵循这个策略时平均能获得多少回报。

接下来还有一个问题：对马里奥来说，“立刻拿到10分”和“100步之后拿到10分”的价值是一样的吗？这取决于任务目标。如果我们希望更重视近期奖励，就可以引入折扣因子（Discount Factor，通常记为 $\gamma$），用来给未来的奖励“算折旧”。通常取 $0 \leq \gamma < 1$；在有限回合的任务中，也可以取 $\gamma=1$，表示不打折。

把未来的奖励按距离现在的远近打折后，再进行求和，我们就得到了折扣回报（Discounted Return）。如果回合在第 $T$ 步结束，那么从第 $t$ 步开始的折扣回报为：

$$G_t = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{T-t-1}R_T = \sum_{k=0}^{T-t-1}\gamma^k R_{t+k+1}.$$

当 $\gamma=1$ 时，它就是前面说的奖励直接求和；当 $0<\gamma<1$ 时，同样大小的正奖励，越早获得，对当前回报的贡献就越大。$\gamma$ 越接近 1，未来奖励保留的权重就越大。

所以强化学习的终极目标非常纯粹：寻找一个最优策略（Optimal Policy，通常记为 $\pi^*$），使得智能体在任务设定下的期望回报最大化。

强化学习最迷人（也最难）的地方在于延迟奖励 (Delayed Reward)。有时候，智能体必须学会“丢车保帅”，放弃眼前的微小得分，去换取几十步之后通关的巨大胜利。

核心总结： 强化学习就是一个智能体在环境中不断**“观察状态 $\rightarrow$ 采取动作 $\rightarrow$ 获得奖励并进入下一个状态”**，并利用交互经验学习和改进策略，以获得更高的期望回报。策略可以每一步更新，也可以积累一段经验后再更新。

二、贝尔曼公式

1. 状态价值：这个位置，到底有没有前途？

上一节中，我们用回报评价一次游玩的表现。但马里奥不可能每次都等到游戏结束，才知道自己刚才走得好不好。站在一个新的位置上，他更想知道的是：“如果从这里开始，按照我现在的玩法继续玩下去，平均能拿到多少分？”

这个问题的答案，在强化学习中称为状态价值函数（State-Value Function），记为 $v_\pi(s)$：

$$v_\pi(s)=\mathbb{E}_\pi[G_t\mid S_t=s].$$

这里的 $s$ 是当前状态，$\pi$ 是接下来遵循的策略，$G_t$表示奖励，$\mathbb{E}$ 表示求期望，也就是把各种可能结果按概率加权平均。用一句话说，$v_\pi(s)$ 就是：从状态 $s$ 出发，按照策略 $\pi$ 行动时，未来回报的平均水平。

比如，马里奥现在站在一条通往旗子的安全道路上，这个状态可能很有价值，即使他脚下暂时没有金币。反过来，眼前虽然有一枚金币，但拿完之后很容易掉进深坑，这个状态的价值就未必高。奖励看的是这一步拿到了什么，价值看的是从这里往后能拿到什么。

而且，价值离不开策略。同样站在深坑边，熟练跳跃的玩家和只会一直向右跑的玩家，接下来的命运完全不同。所以我们要写 $v_\pi(s)$，下标 $\pi$ 就是在提醒自己：“这个评价，是按照哪一种玩法算出来的？”

为了让后面的公式成立，我们假设状态已经包含了预测下一步所需的信息：给定当前状态和动作，下一步状态与奖励的概率分布不再依赖更早的历史。这就是马尔可夫性质（Markov Property）。例如，只知道马里奥的位置可能不够，还需要知道他正在向哪个方向、以多快的速度移动。如果任务有固定的剩余步数限制，也可以把剩余时间放进状态里。

2. 拆开回报：先看这一步，再看后面的路

乍一看，要计算一个状态的价值，好像必须把后面所有可能的路线都走一遍。但回报有一个很方便的特点：它可以拆成“这一步”和“剩下的部分”。

引入折扣因子后，我们可以将第 $T$ 步结束，从第 $t$ 步开始的折扣回报进行如下定义：

$$G_t = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{T-t-1}R_T= \sum_{k=0}^{T-t-1}\gamma^k R_{t+k+1}.$$

把后面的项提取一个 $\gamma$，就会发现：

$$\begin{aligned} G_t &=R_{t+1}+\gamma R_{t+2}+\cdots+\gamma^{T-t-1}R_T\\ &=R_{t+1}+\gamma G_{t+1}. \end{aligned}$$

也就是说：从现在开始的回报 = 这一步的奖励 + 打折后的下一步回报。 这里约定终止时的 $G_T=0$，因为回合已经结束，没有后续奖励了。注意，$G_{t+1}$ 已经包含了从下一步开始的所有后续奖励，并不是只看下一步。所以这种拆法虽然只往前看了一步，却没有把更远的未来丢掉。

把这个关系放进状态价值的定义中，就得到了贝尔曼期望方程（Bellman Expectation Equation）：

$$v_\pi(s)=\mathbb{E}_\pi\left[R_{t+1}+\gamma G_{t+1}\mid S_t=s\right].$$

它的意思非常朴素：当前状态的价值，等于“这一步的奖励 + 下一个状态的折扣价值”的期望。

3. 有多种可能时，就按概率算平均

上面的策略只有一条确定的路，但实际情况可能更复杂：给定的策略可能让马里奥不一定每次都选同一个动作，选了同一个动作后，也不一定每次都得到相同的结果。

为了把这些可能性写清楚，我们用 $\pi(a\mid s)$ 表示“在状态 $s$ 下选择动作 $a$ 的概率”，用 $p(s',r\mid s,a)$ 表示“在状态 $s$ 下采取动作 $a$ 后，进入状态 $s'$ 并获得奖励 $r$ 的概率”。对于离散的状态、动作和奖励，刚才的方程可以展开为【后附证明，证明时，将$s'$和$r$分开表示了，即$p(s'\mid s,a)$表示在s状态采取动作a到达$s'$的概率，$p(r\mid s,a)$表示在状态s采取动作a获得奖励为r的概率】：

$$v_\pi(s)=\sum_a\pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)\left[r+\gamma v_\pi(s')\right].$$

别被两层求和吓到。里面那层是在问：“选定这个动作后，各种结果平均值多少？”外面那层是在问：“按照当前策略选择动作，最后平均值多少？”归根结底，还是把所有可能的“眼前奖励 + 后续价值”按概率加起来。

如果下一步进入终止状态，我们约定它的价值为 0。通关或死亡带来的奖励算在进入终止状态的那一步里，不需要再在终止状态的价值中算一遍。

4. 动作价值：这里有几条路，我该怎么选？

状态价值告诉马里奥“站在这里有没有前途”，但他还需要知道：“现在是向右走好，还是跳起来好？”这就需要动作价值函数（Action-Value Function），记为 $q_\pi(s,a)$【若不好理解，也可以认为其是为了更好的表示贝尔曼公式而存在的】：

$$q_\pi(s,a)=\mathbb{E}_\pi[G_t\mid S_t=s,A_t=a].$$

它表示：在状态 $s$ 下，第一步先采取动作 $a$，之后再按照策略 $\pi$ 行动时，能够获得的期望回报。 第一脚怎么走已经指定了，后面的路才交给策略决定。于是，我们可以先看这个动作会把马里奥带到哪里，再接上下一个状态的价值：

$$q_\pi(s,a)=\sum_{s',r}p(s',r\mid s,a)\left[r+\gamma v_\pi(s')\right].\tag1$$

而状态价值，就是按照策略选择各个动作时，动作价值的加权平均：

$$v_\pi(s)=\sum_a\pi(a\mid s)q_\pi(s,a).\tag2$$

比如，向右走的动作价值是 8，跳跃的动作价值是 12。如果当前策略有一半概率向右走、一半概率跳跃，那么这个状态的价值就是 $0.5\times8+0.5\times12=10$。它不是自动取最高的 12，因为我们现在评价的是当前策略实际上会怎么选。

把这两个关系合起来，还能得到动作价值版本的贝尔曼期望方程【即将(1)式中的$v_\pi(s')$用(2)式替换】：

$$q_\pi(s,a)=\sum_{s',r}p(s',r\mid s,a)\left[r+\gamma\sum_{a'}\pi(a'\mid s')q_\pi(s',a')\right].$$

这里的 $a'$ 是到达下一个状态 $s'$ 后选择的动作。虽然公式变长了，思路依然是“先算眼前，再接上未来”。

5. 从“照现在这样玩”到“怎样玩最好”

到目前为止，我们一直在问：“按照当前策略玩下去，结果怎么样？”但强化学习最终还想回答：“怎样玩，才能得到最高的期望回报？”

我们把所有策略中能够达到的最高状态价值记为 $v_*(s)$，最高动作价值记为 $q_*(s,a)$：

$$v_*(s)=\max_\pi v_\pi(s),\qquad q_*(s,a)=\max_\pi q_\pi(s,a).$$

接下来，以有限状态、有限动作且 $\gamma<1$ 的任务为例。如果马里奥之后也会作出最优选择，那么当前就应该选择“眼前奖励 + 后续折扣价值”期望最大的动作。这就得到了贝尔曼最优方程（Bellman Optimality Equation）：

$$v_*(s)=\max_a\sum_{s',r}p(s',r\mid s,a)\left[r+\gamma v_*(s')\right].$$

它和前面的期望方程最明显的区别是：对动作按当前策略求平均，变成了从动作中选最大值。 但环境结果仍然要按概率求平均，因为马里奥能选择自己按哪个键，却不能指定随机事件一定朝有利的方向发生。

对应的动作价值版本是：

$$q_*(s,a)=\sum_{s',r}p(s',r\mid s,a)\left[r+\gamma\max_{a'}q_*(s',a')\right].$$

这里第一步的动作 $a$ 已经指定，所以最大值出现在下一步：到达 $s'$ 后，再选择那个状态下最好的动作。如果知道了 $q_*$，我们就可以在每个状态选择动作价值最大的动作，得到一个最优策略；如果有多个动作并列最高，任选其中一个即可。

这并不意味着马里奥只顾眼前。假设一个动作马上拿到 5 分，但之后直接结束；另一个动作现在拿到 0 分，却能进入价值为 20 的状态。当 $\gamma=0.9$ 时，两者分别是 $5$ 和 $0+0.9\times20=18$。最优选择会是后者，因为比较的是包含未来的价值。

6. 等式两边都有价值，难道是在绕圈子？

第一次看到贝尔曼方程，很容易觉得奇怪：“为了知道这里值多少，我得先知道下一个地方值多少；那下一个地方的价值又从哪里来？”

其实，贝尔曼方程描述的是各个状态价值之间必须满足的关系。把所有状态的方程放在一起，它们就构成了一个方程组。已知环境的转移与奖励模型时，对于固定策略，可以求解这个方程组，也可以从一组初始估计出发，不断用“眼前奖励 + 后续折扣价值”更新估计。在有限状态、有限动作且 $\gamma<1$ 的标准设定下，反复应用对应的贝尔曼更新，可以分别收敛到当前策略的价值或最优价值。

如果不知道环境模型，就不能直接算出上面的概率加权和，但可以通过实际交互获得样本，学习这些价值。后面会遇到的时序差分学习（Temporal-Difference Learning）和 Q-learning，就会用到这种“拿下一步的价值来帮助估计当前价值”的思路。

核心总结： 贝尔曼公式把一整段未来拆成了**“这一步的奖励 + 下一步的折扣价值”**。贝尔曼期望方程评价“照当前策略玩会怎样”，贝尔曼最优方程刻画“每一步都作出最优选择时能有多好”。它让我们能够通过状态之间的联系，逐步算清一条路究竟值不值得走。
