IoA 与多智能体协作笔记

发表于2026-10-10|更新于2026-10-16|论文阅读

一、IoA & MAS

假设，你现在准备去旅游，需要进行旅游计划的设定。

1、MAS

假定你现在的团队里有三个智能体：行程Agent、酒店Agent、天气Agent

随后你告诉他，你准备规划一次去北京的三日游

接下来，MAS将进行下述工作：行程规划师制定路线。酒店专家提供酒店信息。天气专家提供天气预报。它们交换信息，调整行程，最后给你一份完整的旅游计划。

2、IoA

你不再只有自己团队里的三个 AI 助手，而是可以连接互联网上不同公司、不同平台提供的智能体。

然后，你依旧让其帮你规划一次去北京的三日游

系统可以根据你的需求，发现有哪些智能体可用。判断哪些智能体具备所需能力。选择合适的智能体。建立它们之间的连接，让它们协作完成旅行规划。

3、核心区别

MAS 更多的是研究“这群 AI 怎么合作”；IoA 更进一步关注“怎么从更大的智能体网络中找到合适的 AI，并把它们连接起来合作”。

二、什么是VIT

**ViT（Vision Transformer，视觉Transformer）**是一种让 Transformer“看懂图片”的模型。它的核心思想很直观：

不再像传统卷积网络那样一点点扫描图片，而是把图片切成许多小块，把每个小块当成一个“单词”，再像阅读句子一样理解整张图片。

1. 先把图片切成小块

假设输入图片大小为 (224\times224)，ViT 把它切成很多 (16\times16) 的小方块：

[ 224/16=14 ]

所以一共得到：[ 14\times14=196 ]个图像块，即 Patch。

这也是PE-IoA论文中 Input layer 对应的位置：它负责把原始图像块转换成 Transformer 能处理的 token。

3. 告诉模型每个图块在哪里

如果只给 ViT 196 个图块向量，它不知道哪个来自左上角、哪个来自右下角。因此还要加入位置编码（Positional Encoding）：

ViT 通常在所有图块前加入一个特殊的 CLS token：

CLS 可以理解为一张“汇总纸”。其他图块经过 Transformer 交流后，整张图片的重要信息逐渐汇聚到 CLS 中。

PE-IoA 论文中的共享适配器和个性化适配器分别产生一路 CLS 特征，然后把两路特征拼接起来：

[ h_i^f=\Lambda([h_i^p,h_i^s]) ]

其中：

  • (h_i^p)：个性化适配器产生的特征；
  • (h_i^s)：共享适配器产生的特征；
  • (\Lambda)：融合层；
  • (h_i^f)：融合后的最终特征。

5. 用自注意力理解图块之间的关系

ViT 最重要的机制是自注意力（Self-Attention）。它让每个图块都能判断其他图块与自己有多大关系。

因此，ViT 不只是单独观察每个小块，还会建立整张图片不同区域之间的关系。

通俗地说，传统卷积网络更像：

从附近开始观察，再逐渐扩大视野。

ViT 更像：

每个图块从一开始就可以查看整张图，并决定应该关注哪些其他图块。

6. 多头注意力是什么？

ViT 通常使用多头注意力（Multi-Head Attention）。可以把每个“头”理解成一种不同的观察角度：

  • 一个头关注形状；
  • 一个头关注颜色；
  • 一个头关注物体各部分的位置关系；
  • 一个头关注前景与背景。

然后把这些观察结果综合起来。

7. ViT 的整体流程

可以简化为：

[ \text{图片}\rightarrow\text{图块序列} \rightarrow\text{Transformer} \rightarrow\text{CLS} \rightarrow\text{分类结果} ]

8. ViT 与传统 CNN 有什么不同？

对比 CNN ViT
看图片的方式 使用卷积核扫描局部区域 把图片切成图块序列
初始视野 主要关注邻近像素 可直接联系远距离图块
核心机制 卷积 自注意力
内置图像规律 较强，例如局部性 较弱，需要从数据中学习
数据需求 相对较低 通常需要更多数据或预训练
与语言模型的关系 架构不同 与语言 Transformer 高度相似

CNN 像一个人拿着放大镜从左到右查看图片；ViT 像把所有图块摆在桌上，同时分析它们之间的关系。

9. 为什么论文选择 ViT？

因为 ViT 参数量较大，而且结构与 LLM 都建立在 Transformer 上，适合验证：

  1. 冻结大型主干是否能节省训练成本；
  2. Adapter 是否能以少量参数调整模型；
  3. 多个智能体是否可以只交换 Adapter；
  4. 共享知识和个性化知识能否分开学习。

在 PE-IoA 中：

例如 Office-Home：

  • 个性化 Adapter 学习 Art、Clipart 或 Product 的特殊风格；
  • 共享 Adapter 学习“椅子、电脑、杯子”等跨域通用结构。

不过，ViT 与 LLM 架构相似不等于任务相同。ViT 实验只能证明 PE-IoA 对 Transformer 视觉分类有效，不能直接证明它对语言智能体的推理、规划和工具调用同样有效。

三、PE-IoA

1、在去中心化的智能体网络中应用大模型会存在什么问题？

  • 沟通与计算成本太高：智能体之间互相传输和更新知识需要耗费极大的算力和网络带宽，导致成本过高。
  • 协作机制太僵化：现有的训练模式要么“各扫门前雪”（完全独立），要么“吃大锅饭”（强制统一），无法让智能体之间实现灵活且精细的共同进步。
  • 难以平衡“团队共性”与“个人特长”： 每个智能体都有自己的专属任务，导致掌握的信息不同。如果强行让大家共享统一的知识，会抹杀它们各自的专业优势；如果完全不共享，又会变成一盘散沙，失去合作的意义，导致团队很难步调一致地做决策。

2、Related work

早期的基于通信的方法（CommNet & DIAL) 在实际应用中不可行。

后续研究（例如 TarMAC, OPV2V) 有限且存在偏差的数据集可能导致模型过拟合。

DiscoNet 和 MKD-Cooper 等知识蒸馏框架。降低了成本，但它们是静态的，不支持对同伴知识进行动态且具有上下文感知能力的整合。此外，它们往往过度压缩信息，导致在演化环境中的语义丰富性和适应性丧失。

LoRA 和 Adapter Tuning 等参数高效微调（PEFT）的方法主要针对单智能体或集中式环境设计，缺乏对智能体间协作的支持

3、PE-IoA要做什么？怎么做的？

无中央服务器的条件下，同时获得低成本通信、群体知识共享和个体适应能力。

构建了一个双适配器结构：

组件 作用
冻结主干 (\theta_{\text{freeze}}) 提供通用表示
个性化适配器 (v_i) 学习本地数据、角色偏好
共享适配器 (w_i) 吸收并传播群体知识
融合层 (\Lambda) 拼接两路 CLS 特征，1536→768

4、PE-IoA的训练过程

  1. 每个智能体在不同的域【例如，某一个域里面只有艺术画】同时训练$v_i$,τ次。
  2. 每个智能体训练完$v_i$之后，再更新各自的共享适配器$w_i$
  3. 随后再与邻居智能体交换并聚合共享适配器

5、PE-IoA 的实验设计思路是怎样的

PE-IoA 的实验围绕四个递进问题展开：

1. 构造多智能体异构环境

作者选择三个跨域图像分类数据集：

数据集 域/智能体数量 特点
Office-Home 4 65 类，约 1.55 万张图像
Office-Caltech10 4 10 类，规模较小
DomainNet 6 345 类，约 60 万张图像，异质性最强

每个“域”分配给一个智能体。例如 Office-Home 的 Art、Clipart、Product、Real-World 分别由四个节点持有。智能体只看到本域的部分标注数据，默认训练比例为 80%，且不同域中同一类别的样本数量不相同。即[ P_1(x,y)\neq P_2(x,y)\neq\cdots\neq P_N(x,y) ]。

2. 设置三种通信拓扑

拓扑 通信方式 难度
FC 每个智能体都与其他智能体连接 通信最充分
ER 随机稀疏连接，但整体连通 中等
Ring 每个智能体主要与相邻节点连接 通信最受限

如果方法只在 FC 中有效，说明它依赖高强度通信。PE-IoA 在三种拓扑间波动较小，构成了论文的拓扑鲁棒性证据。

3. 设置三类比较对象

  • Indep：每个智能体独立训练完整模型，不通信；
  • DSGD-SIM：共享部分和个性化部分同时更新；
  • DSGD-ALT：共享部分和个性化部分交替更新；
  • PE-IoA：冻结 ViT，只训练双适配器，并仅通信共享适配器。

SIM/ALT 又分别测试 Input、Out、Adapter 三个个性化位置，因此实际形成六个传统个性化基线。

这一比较试图回答两个问题：

  1. 与完全独立训练相比，智能体通信有没有价值？
  2. 与传统共享大模型相比，只传共享 Adapter 是否更高效？

4. 同时测量性能和成本

论文采用三类指标：分类准确率；每轮通信参数量；本地训练参数量。

例如 Office-Home 上：

方法 准确率（FC） 通信参数 训练参数
独立全模型 83.54% 0 85.85M
DSGD-SIM Out 87.75% 85.80M 85.85M
PE-IoA 87.55% 0.96M 1.92M

这组结果揭示了论文真正的优势：PE-IoA 不一定始终取得最高准确率，但能以不到传统方法 2% 的参数开销取得接近最优的性能。

5. 通过消融实验解释原因

作者进一步验证了：

  • 图3：改变 Adapter 压缩倍数，验证准确率与参数量的折中；
  • 图4：比较独立、固定个性化和自适应个性化；
  • 图5：展示不同智能体的数据量和类别分布确实不均衡；
  • 图6：设置 10% 掉线率，检查通信不稳定时是否仍能收敛。

因此，整套实验的基本逻辑是：

主实验验证效果，拓扑实验验证稳定性，参数统计验证效率，消融实验解释机制。

6、可以从 PE-IoA 学到什么，并应用到后续科研中？

1. 把“共享知识”和“个性知识”显式分开

[ \text{智能体能力} = \text{共享知识} + \text{个性化知识} ]

可以把不同知识分别放入不同模块：

信息类型 适合放置的位置
通用推理策略 共享 Adapter
角色、偏好、私有领域知识 个性化 Adapter
大规模基础能力 冻结主干
如何组合两类知识 可学习融合层

该思路可以进一步用于 LLM 智能体：共享 Adapter 学习协作和任务分解，私有 Adapter 学习每个智能体的角色与专业知识。

2. 通信应交换“知识增量”，而不是完整模型

协作所需的信息量，可以远小于模型本身的参数量。

3. 实验设计应从性能扩展到系统成本

[ \text{效果、通信量、训练量、显存、延迟、能耗} ]

4. 下一步最有价值的研究想法

  • 根据任务动态选择共享或私有 Adapter；
  • 不同智能体按数据量使用不同 Adapter 宽度；
  • 根据邻居知识价值学习通信权重，而非固定矩阵 (P)；
  • 异步更新，避免快节点等待慢节点；
  • 检测恶意或低质量 Adapter 更新；
  • 将共享 Adapter 扩展到 LLM 的规划、工具调用和多轮协作。

7、PE-IoA 的局限在哪里？

1. 尚未真正验证 LLM 智能体

实验全部是 ViT 图像分类。实验中的“智能体”本质上是持有不同数据分区的训练节点，并未涉及：

  • 对话和自然语言推理；
  • 任务规划；
  • 工具调用；
  • 智能体之间的语义消息；
  • 长期记忆和角色协作。

2. 准确率并非全面优于基线

论文最可靠的结论：

PE-IoA 以极低成本取得有竞争力的准确率。

3. 成本指标只是参数量代理

论文用“传输了多少参数”代表通信成本，用“更新了多少参数”代表训练成本，但没有直接报告：

  • 实际传输字节；
  • 通信延迟；
  • 训练时间；
  • GPU 显存；
  • FLOPs；
  • 能耗。

参数减少 98%不必然意味着端到端时间也减少 98%，因为还存在协议、同步和硬件开销。

4. 理论假设比现实理想

收敛分析依赖平滑损失、梯度方差有界、双随机通信矩阵和连通网络等假设。现实 IoA 中可能存在：

  • 节点异步；
  • 算力和数据量差异；
  • 长期掉线；
  • 网络拓扑不断变化；
  • 恶意或错误更新；
  • Adapter 版本不一致。

论文只测试了 10%的随机掉线，尚不足以覆盖这些复杂情形。

PE-IoA 的主要价值是提出了一个清晰且高效的“冻结主干、共享小模块、保留私有模块”架构。关于真实 LLM 智能体协作、统计稳定性和现实系统收益的结论，仍需要更强实验验证。
